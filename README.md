## What I'm working on now

An online shop for an Australian landscaping and turf supplier, built on WordPress and WooCommerce, mostly used on phones:

- **Custom WordPress theme** in PHP: shop, product pages, cart and checkout built mobile-first.
- **Inventory/POS integration:** connecting the shop to a company-wide inventory system over its REST API, so price, stock, orders and customer accounts come from one place for several brands.
- **API testing:** writing test plans, probing endpoints, and turning bugs into clear reports for the backend team (including a security issue found before launch).
- **Delivery pricing** by road distance (Google Maps), hire-equipment booking, Stripe checkout.
- **Speed and SEO:** Core Web Vitals, caching (Varnish, Cloudflare, Redis), structured data, sitemaps.
- **Deploys** through Git to a Cloudways staging server, with browser tests in Playwright.
